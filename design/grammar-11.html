Passiversatzformen

Wiederholungen von "werden" klingen oft eintönig. Im C1-Niveau nutzen wir Alternativen, um Möglichkeiten oder Notwendigkeiten eleganter auszudrücken.

Adjektivendung

Können + Passiv
sein + Adj (-bar / -lich)

Das Wasser kann getrunken werden.
↓
Das Wasser ist trinkbar.

Reflexiv

Können + Passiv
sich lassen + Infinitiv

Das Problem kann gelöst werden.
↓
Das Problem lässt sich lösen.

Die "Zu"-Form

Müssen / Können + Passiv
sein + zu + Infinitiv

Die Rechnung muss bezahlt werden.
↓
Die Rechnung ist zu bezahlen.
